Skystore: Ваш Магазин Цифровых Продуктов

Интернет-магазин для удобной и быстрой продажи плагинов, примеров кода, шаблонов и других цифровых продуктов.


1. Описание Проекта
Skystore — это специализированная платформа для публикации и продажи различных цифровых товаров, таких как плагины, скрипты, темы и прочие наработки. Проект призван обеспечить продавцам удобный инструмент для монетизации их интеллектуальной собственности, а покупателям — интуитивно понятный интерфейс для поиска и приобретения нужных решений.
Основные функции:

- Каталог товаров: Простой и понятный просмотр доступных продуктов.

- Детальные страницы продуктов: Подробная информация о каждом товаре, включая описание, цену и особенности.

- Контактная информация: Возможность связаться с администрацией или поддержкой.

- (Предполагается: Корзина покупок, система оплаты, личный кабинет пользователя, админ-панель для управления товарами и заказами.)
Установка и Настройка

Для запуска проекта на вашей локальной машине выполните следующие шаги:

2. Предварительные требования


- Python 3.8+

- pip (менеджер пакетов Python)

- PostgreSQL (система управления базами данных)

- Git


3. Шаги установки 
a)Клонируйте репозиторий:
bash
    git clone https://github.com/TatyanaKuleva/online_shop_hw.git

b)Создайте и активируйте виртуальное окружение:

- Linux/macOS:
bash
    python3 -m venv venv
    source venv/bin/activate

- Windows:
bash
    py -m venv venv
    .\venv\Scripts\activate

c)Установите все необходимые зависимости:
bash
    pip install -r requirements.txt



d)Настройте базу данных PostgreSQL:

- Создайте новую базу данных (например, skystore_db) и пользователя PostgreSQL с доступом к этой базе.

- Откройте файл skystore/settings.py и обновите настройки DATABASES в соответствии с вашими данными:
    python
    DATABASES = {
        'default': {
            'ENGINE': 'django.db.backends.postgresql',
            'NAME': 'skystore_db',         # Название вашей БД
            'USER': 'skystore_user',      # Имя пользователя БД
            'PASSWORD': 'your_password',  # Пароль пользователя БД
            'HOST': 'localhost',
            'PORT': '5432',
        }
    }

e) Выполните миграции базы данных:
bash
    python manage.py migrate



f) Создайте суперпользователя (для доступа к админ-панели):
bash
    python manage.py createsuperuser
    Следуйте инструкциям в консоли для создания имени пользователя, email и пароля.

4. Использование
После завершения установки вы можете запустить сервер разработки:

Запустите сервер Django:
bash
    python manage.py runserver
    Сервер будет доступен по адресу: http://127.0.0.1:8000/.

Просмотр каталога:
    Откройте http://127.0.0.1:8000/home/
